будет реализована логика создания вершин графа, создания по этим вершинам сетки, 
где некоторая вершина соединена с вершиной справа и снизу, 
образуя сетку, после чего сделай алгоритм поиска кратчайшего пути от начальной 
вершины до конечной вершины, делая эти алгоритмы, учти что далее в решение будут добавлены 
"кастомные" вершины чьи рёбра будут взвешены (будет даваться двумерный массив), где будут 
названия тайлов и если название какое-то заготовленное ("NULL")

есть 2 варианта реализации:
в начальный 3 функции создание вершин, рёбер, поиск пути от точки до точки
в конечной то же самое, но со всеми фишками

уточню, что создание рёбер по вершинам важно, так как будут 
препятствия, которые следует обходить (они реализованы через удаление вершин из графа) 
будет отдельный функционал (исключение из генерации вершин, а следовательно рёбер графа)
